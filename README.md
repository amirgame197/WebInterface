# WebInterfaceSample
A sample web interface that acts as a control panel for a specific configurable process.

This file does nothing by itself.

How to use:
1. Copy "WebInterface" directory to the same directory as the executable working directory.
2. Edit the "config.py" inside "WebInterface", set the required variables.
3. Once the interface port is set-up and not conflicting, run with "python3 WebInterface/server.py".
4. Working directory should be the same directory where "WebInterface" directory is located.
